# Contribuer

Merci de votre intérêt pour ce projet.

## Problèmes et demandes

Avant de proposer une modification importante, veuillez ouvrir une issue pour discuter de la proposition.

## Workflow de contribution

1. Fork du dépôt
2. Créez une branche dédiée :
   ```bash
   git checkout -b feature/ma-nouvelle-fonctionnalite
   ```
3. Effectuez vos modifications
4. Vérifiez le projet :
   ```bash
   bun run lint
   bun run build
   ```
5. Ouvrez une pull request avec une description claire

## Standards

- Respectez les conventions TypeScript et React
- Rédigez un code lisible et maintenable
- Ajoutez ou mettez à jour la documentation si nécessaire
- Vérifiez que les changements ne cassent pas le build

## Code de conduite

Veuillez garder un comportement respectueux et constructif dans les discussions et les contributions.
